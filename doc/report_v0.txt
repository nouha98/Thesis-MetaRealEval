% ─────────────────────────────────────────────────────────────────────────────

\subsubsection*{Evaluation Protocol}

The following models are evaluated through OpenRouter:

\begin{itemize}[noitemsep]
    \item Gemma-4-31B
    \item Llama-3.3-70B
    \item Qwen3-Coder
\end{itemize}

For each \textit{(task, prompt variant, model)} combination:

\begin{enumerate}[noitemsep]
    \item Generate $n=10$ completions
    \item Compute Pass@1 and Pass@k
    \item Compare rankings across paraphrases using Kendall's $\tau_b$
\end{enumerate}

\vspace{4pt}

\textbf{Goal:}
Measure whether semantically equivalent prompts lead to unstable benchmark rankings.

\section{Limitations \& Mitigations}
% ═════════════════════════════════════════════════════════════════════════════

\begin{itemize}[noitemsep]
    \item \textbf{API Limits \& \texttt{--mock} Data:} Severe rate limits (HTTP 429) on the OpenRouter free-tier disrupted early evaluation runs. To ensure development could continue, a \texttt{--mock} execution mode was added to the RQ2 pipeline. This mode uses deterministic, synthetic scores (instead of real LLM outputs) to mathematically validate the batched sampling, Kendall $\tau_b$ rankings, and disk-caching mechanisms without consuming API quota.
    \item \textbf{Pilot Scope:} The current RQ2 results presented use this synthetic mock data on a limited 2-task pilot. Robust statistical tests (Wilcoxon/Cliff's $\delta$) will be used once true empirical data is collected.
    \item \textbf{Mutation Fallbacks:} To bypass API dependencies during RQ1 fault generation, a secure local AST-based fallback was implemented to inject LLM-like semantic faults offline.
\end{itemize}

% ═════════════════════════════════════════════════════════════════════════════
\section{Next Steps}
% ═════════════════════════════════════════════════════════════════════════════

\begin{enumerate}[noitemsep]
    \item \textbf{Scale Pilot (Phase 2):} Execute RQ1 and RQ2 on the full 164-task HumanEval benchmark using a paid-tier API or multi-day batched runs.
    \item \textbf{False-Positive Detection (Phase 3 - RQ3):} Implement automated false-positive mutant detection (SBC scoring and divergence tracking).
    \item \textbf{Test Suite Augmentation (Phase 4 - RQ4):} Build Metamorphic Testing-augmented test suites and evaluate benchmark ranking recovery.
\end{enumerate}
